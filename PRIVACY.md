# Privacy Notice

OutplayArena does not track, collect, or store any personal information about its users. No analytics, telemetry, cookies (beyond essential session cookies for authentication), or third-party tracking services are used.

If you authenticate via a third-party provider (GitHub, Google), OutplayArena stores only the minimal profile information required for account identification: your provider user ID, display name, email address, and avatar URL. This data is never shared with any third party.

This project is open-source software. You can inspect the full source code at the [OutplayArena repository](https://github.com/outplaylabs/arena).
