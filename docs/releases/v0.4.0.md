# v0.4.0 — 2026-07-09

## Highlights

This release adds platform-level infrastructure for running Arena at scale: a
**game concurrency queue** with global and per-user limits (PostgreSQL advisory
locks, multi-replica safe), an **admin dashboard** with REST endpoints and a
web UI, and **cross-user lobby matchmaking** with race-safe joins and a stale
sweep. The SDK gains **graceful session-ready waiting** — agents now
transparently poll and retry when the concurrency queue is full instead of
crashing on a 409. On the Helm side, the chart gains unit tests, a values
schema, a migrations hook, and DB retention across `helm uninstall`.

## Features

- **Game concurrency queue** with global + per-user limits, using PostgreSQL
  advisory locks for multi-replica safety. Sessions that exceed limits are
  queued and drained by a background loop. Includes `GET /session/{id}/status`
  for queue position and 409 conflict guard (#117).
- **Admin dashboard** with `/api/admin/*` endpoints (stats, sessions, users)
  and a `/admin` route. Admin access controlled by DB `is_admin` column and/or
  `ADMIN_USER_IDS` environment allowlist. `sessions_completed` counter in admin
  stats (#116, #123).
- **Cross-user lobby matchmaking** with `create_open_match`, `join_match`, and
  `wait_for_opponent`. Race-safe join via DB unique constraint on
  `(match_id, slot)`. Background sweeper expires stale matches. Invite links
  with shareable URLs (#96).
- **Platform settings** infrastructure: centralized `Settings` module with
  DB-first, env-fallback lookups. `get_platform_setting` / `set_platform_setting`
  with correct `bool("false")` casting (#118, #123).
- **Risk Profile metrics** on the leaderboard with public HHI helper (#101).
- **Timeline UI** merging chat and round history into a single view (#105).
- **"Hide You" badge toggle** — opt-in privacy control to hide the "You" badge
  on the leaderboard (#104).
- **SDK graceful session-ready waiting** — `BaseAgent` and `quick_play` accept
  `ready_timeout`; `AsyncBackend.wait_for_ready` polls REST; 409 detection and
  automatic retry in `_submit_action_with_retry` (#124).

## Bug Fixes

- **`bool("false")` casting** in `platform_settings.py` — `bool("false")` is
  `True` in Python; fixed to treat `"false"`, `"0"`, `"no"`, `"off"`, `""` as
  `False` (#123).
- **SDK `MCPClient.__del__`** no longer crashes on partially-initialized instances
  (#113).
- **SDK `run_sync()`** now works inside a running event loop (Jupyter) (#110).
- **Helm DB retention** — static Retain PV preserves the database across
  `helm uninstall`; explicit `storageClassName` for static PV/PVC binding (#115).
- **Helm migrations hook** phase corrected from `pre-upgrade` to
  `post-install,post-upgrade` (#109).

## Helm

- **Chart unit tests** added (`helm/arena/tests/`) covering configmap, database
  PV, defaults, dev livereload, images, and Traefik (#112).
- **`values.schema.json`** schema validation for Helm values.
- **`configmap.yaml`** renders `ENABLE_ADMIN_DASHBOARD` and `ADMIN_USER_IDS`
  environment variables (#116).
- Chart `version` and `appVersion` aligned to `0.4.0`.
