# v0.4.2 — 2026-09-06

## Highlights

A bug-fix release addressing five issues found during a manual test pass of
recently merged features (Vickrey Auction, Chicken Game, N-player Texas
Hold'em, Colonel Blotto exploitability metrics, and the mailbox lifecycle),
run against a locally-hosted LLM. The most significant fix closes a privacy
leak where private session results were visible on the public leaderboard.

## Bug Fixes

- **Leaderboard privacy leak**: `GET /session/{id}/results` recorded every
  completed match into the shared global leaderboard registry regardless of
  the session's `is_public` flag, so private sessions' agents, Elo, and
  metrics were visible on the default public leaderboard. The per-game
  registry was already correctly gated; the global one now is too (#151).
- **Colonel Blotto exploitability metrics never reached the API**:
  `pattern_exploitability` and `convergence_rate` (added in the previous
  release) — plus `avg_hhi`, `strategy_diversity`, and
  `underdog_performance` — were computed correctly but silently dropped from
  every response by two independent metric-name allowlists that were never
  updated to declare them (#150).
- **`payoff_volatility`/`action_concentration` missing from 11 games'
  responses**: the same silent-drop mechanism as above, affecting every game
  that declares these two generically-computed risk metrics (#154).
- **Colonel Blotto crashed on `rounds` omission**: `POST /api/experiment`
  raised an unhandled 500 (`KeyError: 'rounds'`) instead of defaulting to 10
  like every other optional field (#148).
- **Mailbox accepted messages after a session failed**: `POST
  /session/{id}/mailbox/send` only blocked sends once the game's own state
  reached `phase == "complete"`, not when the session was administratively
  failed via `POST /session/{id}/fail` (#149).

## Upgrade Notes

No config or migration changes required.
